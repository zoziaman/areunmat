개인정보처리방침

시행일: 2026년 11월 8일

"아는맛언니 쇼츠 도구"(이하 "도구")는 유튜브 채널 아는맛언니의 운영자가 자기 PC에서만 사용하는 개인용 프로그램입니다.

1. 사용하는 Google 데이터

도구는 운영자 본인이 승인한 Google 계정에 대해 다음 YouTube Data API 권한만 사용합니다.

  • youtube.upload: 운영자가 만든 쇼츠 영상을 운영자 본인의 채널에 비공개로 올리고 공개 시각을 예약하기 위해
  • youtube: 업로드한 영상의 상태 확인, 채널 배너·설명 등 운영자 본인 채널의 설정 변경을 위해

2. 저장과 보관

Google이 발급한 인증 토큰은 운영자의 PC 안에만 저장되며, 외부 서버로 보내지 않습니다. 도구는 다른 사람의 계정, 시청자 정보, 댓글 작성자 정보 등 개인정보를 수집하지 않습니다.

3. 공유

도구가 다루는 Google 사용자 데이터는 어떤 제3자에게도 판매·공유·전송하지 않으며, 광고 목적으로 사용하지 않습니다. Google API에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 권한 철회와 삭제

운영자는 언제든지 Google 계정의 타사 앱 액세스 권한에서 도구의 권한을 철회할 수 있고, PC에 저장된 토큰 파일을 지우면 모든 인증 정보가 삭제됩니다.

5. 문의

유튜브 채널 아는맛언니의 정보 탭을 통해 문의할 수 있습니다.
